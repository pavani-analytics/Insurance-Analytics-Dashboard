# Insurance-Analytics-Dashboard

## Project Overview

This project analyzes insurance policy, customer, claims, and payment data using Excel, Power BI, Tableau, and SQL to uncover insights into policy performance, customer demographics, claim trends, payment behavior, and business growth. The project includes data modeling, KPI tracking, calculated columns, and interactive dashboards to support data-driven decision-making.

## Dataset

📊 Download Dataset

The dataset consists of four tables:

### Policy Details

* Policy ID
* Policy Type
* Coverage Amount
* Premium Amount
* Policy Start Date
* Policy End Date
* Payment Frequency
* Policy Status
* Customer ID

### Claims

* Claim ID
* Date of Claim
* Claim Amount
* Claim Status
* Reason for Claim
* Settlement Date
* Policy ID

### Payment History

* Payment ID
* Date of Payment
* Amount Paid
* Payment Method
* Payment Status
* Policy ID

### Additional Details

* Agent ID
* Renewal Status
* Policy Discount
* Risk Score
* Policy ID

## Data Preparation

### Data Modeling

* Established relationships between Policy Details, Claims, Payment History, and Additional Details tables.
* Performed data cleaning and transformation.

### Calculated Column

* Created a calculated column to identify policies expiring in the current year by comparing Policy End Year with the Current Year.
